# neonlan_arcade

NeonLAN Arcade is a neon‑themed multiplayer mini‑game platform designed for players on the same Wi‑Fi or local network.  
Built using **Node.js, Express, and Socket.IO**, it allows fast, real‑time gameplay through the browser with no downloads required.

This project aims to provide a collection of simple, fun, LAN‑friendly multiplayer games with a stylish neon arcade design.

---

## 🎮 Features

- ⚡ Real‑time multiplayer via Socket.IO  
- 🌐 LAN‑based local play (same network)  
- 🎨 Neon arcade UI theme  
- 🕹 Game hub menu  
- 🎲 Expandable game framework  
- 📂 Organized project structure
